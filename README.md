# Dental Clinic Management System

Capstone project. Multi-branch dental clinic with web (admin/dentist/receptionist) and mobile (patient) apps, AI-assisted appointment scheduling, and CAMBRA-based risk assessment.

## Stack
- Backend: Node.js + Express + MySQL
- Web: React + Vite
- Mobile: React Native + Expo
- Hosting: Railway (backend + database), Cloudinary (media)

## Folders
- `backend/` — Express API, single backend serving both clients
- `web/` — admin, dentist, receptionist (React)
- `mobile/` — patient app (React Native + Expo)
